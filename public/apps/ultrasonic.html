Ultrasonic Test Record

UltraTest BP-700 Pro — runs from a small program on the PC the instrument is plugged into
This page is a launcher, not the tool itself. The actual recording page is served by a small program (bridge.py) that has to be running on this computer, because reading the instrument's USB port is something a web page cannot do on its own.

Open the tool

If the bridge program is already running on this PC, open its page here:

Open Ultrasonic Test Record ↗

This only works on the PC that has the instrument plugged in and the bridge program running. On any other computer, the link above will fail to load — that is expected, not a bug.

First time on this PC?

  1. Copy the tools/ultrasonic-bridge folder from this project onto the PC with the instrument.
  2. Install Python 3.9 or newer from python.org (tick "Add python.exe to PATH" during setup).
  3. Double-click start_bridge.bat in that folder, and choose option 6 once to install the required packages.
  4. Plug in the BP-700 Pro over USB and switch it on, then run start_bridge.bat again and choose how it should read the instrument:
    • 1 — Instrument over USB: live readings read directly from the instrument's USB port.
    • 2 — Watch the export folder: point it at a folder where UltraTestLab exports CSV/XLSX files.
    • 3 — Demo: simulated readings, for trying the page out — never used for real records.
  5. It opens its page automatically in the browser; after that, the Open the tool link above will work.

Full setup notes, troubleshooting and the factory-network option are in tools/ultrasonic-bridge/README.md.

What stays where

Readings and saved test records are kept only in a small database file (us_records.db) next to bridge.py, on that one PC — they are not shared with the rest of the Ferentino Management System. Back that file up the same way you would any other important file on that PC (for example, a scheduled copy to OneDrive).
